# Assets and attribution

The first machinery art set was generated through **fal.ai** using **openai/gpt-image-2** (mill) and **fal-ai/nano-banana-2/edit** (reference variants). The large gear derives from the small gear image. Magenta backgrounds were removed locally, including enclosed holes; sprites use hard alpha, point filtering, a reduced palette and a dark outline.

The assets are original generated designs. No Minecraft/Create textures, Sun Haven sprites or extracted game assets are included. Model/service terms apply to generated outputs; the MIT license in this repository covers original code and documentation, not a guarantee of exclusive copyright in generated images.

[Provenance](assets/fal_manifest.jsonl) records successful endpoint requests and prompts with local-machine references removed. Generation was performed on 14 October 2026. Wheel-body, mill and belt animations remain unfinished.

Code and documentation were developed with Codex (GPT-6). The project adapts ideas rather than redistributing the original Create mod. It is not affiliated with Pixel Sprout Studios or Creators of Create.

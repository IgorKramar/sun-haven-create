# Roadmap

The goal is a substantial Create-inspired automation mod that fits Sun Haven. Version 0.3.0 is the first playable chain, not a complete port. This roadmap is a proposed order of work; there are no committed dates.

## First playable chain — implemented

- [x] Seven machine types, rotation, gear ratios, stress and source conflicts.
- [x] Native resources, construction costs, refunds and persistent buffers.
- [x] Wheel → shaft → mill → belt → chest in the real game.
- [x] Original first sprite set and solar workshop note.

## Polish and native progression

- [ ] Separate rotating wheel art from its static support.
- [ ] Animate milling, belt movement and visible transported items.
- [ ] Improve sprite scale, placement previews and construction feedback.
- [ ] Add native items, recipes, unlocks and a workshop introduction.
- [ ] Replace the simplified wheel power source with water-aware placement.
- [ ] Check newer game builds and interoperability with other mods.

## Production and logistics

- [ ] Pressing, crushing, mixing, fans and mechanical assembly.
- [ ] Funnels, filters, routing and multiple native-resource production chains.
- [ ] Fluid transport and processing.
- [ ] Decide and verify off-scene production behavior.

## Moving machinery and travel

- [ ] Moving constructions, attachments and collision rules suitable for a 2D world.
- [ ] Rail building, vehicles, schedules and station logistics.
- [ ] Multiplayer replication only after a separate design and real multiplayer tests.

## World integration

- [ ] Human Sun Haven workshop progression.
- [ ] Nature/mana technology for Nel’Vari and night-themed machinery for Withergate.
- [ ] Original mod stories consistent with the host setting, clearly distinct from official canon.
